# Ajay Love Quiz ❤️

A single-file romantic website. Open `index.html` in a browser to test it.

## GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public `https://...github.io/.../` link.

No backend is required. Answers are not sent to a server; everything runs in the browser.
